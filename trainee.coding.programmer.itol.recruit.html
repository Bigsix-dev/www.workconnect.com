Trainee Coding & Programmer

Job Description

ITOL Recruit is offering an opportunity for individuals looking to begin a career in coding and software programming. The role is designed for motivated candidates who want to develop practical programming knowledge and build the technical skills required for entry-level software development positions. Successful candidates will receive structured development and practical learning opportunities.

Responsibilities

  • Learn and apply fundamental programming concepts.
  • Develop simple applications and coding projects.
  • Write, test, and improve computer code.
  • Assist with debugging and resolving basic programming issues.
  • Work with development tools and programming environments.
  • Follow coding standards and development procedures.
  • Participate in technical learning and development activities.
  • Work towards developing the skills required for professional programming roles.

Requirements

  • Strong interest in coding, programming, and technology.
  • No extensive professional programming experience required for a trainee role.
  • Good logical thinking and problem-solving ability.
  • Willingness to learn new programming languages and technologies.
  • Good attention to detail.
  • Ability to work independently and as part of a team.
  • Basic computer literacy.
  • Relevant coding or IT experience is advantageous but not essential.

Working Hours

  • Full-time position.
  • Standard professional working hours.
  • Training and development activities may form part of the working schedule.

Salary

  • £27,000–£40,000 per year.

Benefits

  • Structured technology training.
  • Opportunity to build practical coding experience.
  • Career development support.
  • Exposure to programming tools and technologies.
  • Opportunity to progress into software development roles.
  • Supportive learning environment.
