Web Developer Placement Programme

Job Description

Career Change is providing an opportunity for aspiring web developers to gain practical experience and develop the skills required for a career in web development. The programme is aimed at individuals seeking to transition into technology and build experience through practical development work, projects, and professional exposure.

Responsibilities

  • Develop and maintain websites and web-based applications.
  • Create responsive and user-friendly web pages.
  • Work with HTML, CSS, JavaScript, and other web technologies.
  • Assist with testing websites across different devices and browsers.
  • Identify and resolve basic website issues.
  • Work on practical web development projects.
  • Follow development standards and best practices.
  • Build and maintain a portfolio of practical web development work.

Requirements

  • Strong interest in web development and digital technology.
  • Basic knowledge of HTML and CSS is beneficial.
  • Willingness to learn JavaScript and modern web technologies.
  • Good problem-solving and logical thinking skills.
  • Creative approach to website design and development.
  • Good attention to detail.
  • Ability to learn independently and work collaboratively.
  • Previous professional web development experience is not essential.

Working Hours

  • Full-time placement programme.
  • Working hours based around programme and project requirements.
  • Practical development activities form part of the programme.

Salary

  • Salary not stated.

Benefits

  • Practical web development experience.
  • Opportunity to build a professional portfolio.
  • Exposure to real-world development projects.
  • Technology career development support.
  • Opportunity to develop industry-relevant technical skills.
  • Potential pathway into future web development opportunities.
