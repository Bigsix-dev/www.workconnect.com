Software Developer

Job Description

Spectrum IT Recruitment is seeking a talented Software Developer to design, develop, test, and maintain high-quality software applications. The successful candidate will work closely with development and technical teams to deliver reliable solutions that meet business and user requirements. This position offers the opportunity to work on challenging software projects within a professional development environment.

Responsibilities

  • Design and develop software applications and technical solutions.
  • Write clean, maintainable, and efficient code.
  • Test applications and resolve software defects.
  • Work with developers, designers, analysts, and other technical stakeholders.
  • Review existing code and contribute to software improvements.
  • Participate in development planning and technical discussions.
  • Maintain technical documentation for software systems.
  • Support deployment and maintenance of developed applications.

Requirements

  • Professional experience in software development.
  • Strong programming skills in relevant development languages.
  • Good understanding of software development principles and practices.
  • Experience with version control and development tools.
  • Strong debugging and problem-solving abilities.
  • Good understanding of databases and application architecture.
  • Ability to work collaboratively within a development team.
  • Relevant computer science, software engineering, or equivalent experience is desirable.

Working Hours

  • Full-time position.
  • Standard professional working hours.
  • Flexible or hybrid working may be available depending on the employer.

Salary

  • £65,000–£70,000 per year.

Benefits

  • Competitive software development salary.
  • Professional development opportunities.
  • Access to modern development technologies.
  • Opportunities to work on challenging software projects.
  • Career progression within software engineering.
  • Collaborative technical working environment.
